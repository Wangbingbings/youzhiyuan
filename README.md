# 🎒 幼稚园 · Child Sticker Avatar

> 上传一张儿童人脸参考图，生成**白底大头像**。真实照片质感的脸部 + 贴纸/手账风装饰，可输出贴纸头像、Q版大头贴、可爱大头照等 1:1 方图。

适合**给孩子的照片做头像/贴纸**的场景，按性别走不同风格模板：

| 性别 | 风格 |
|------|------|
| 👧 女孩 | 真实脸部 + 贴纸装饰（默认双丸子头 + 红苹果道具） |
| 👦 男孩 | 二选一：**模板A** Y2K未来感（耳机）/ **模板B** 藏式坏笑（绿松石耳环 + 墨镜） |

---

## ✨ 功能特性

- **图生图保真**：基于参考图保留孩子的真实五官、脸型与皮肤质感，禁止卡通化/Q版化
- **按性别路由**：女孩走贴纸装饰模板，男孩走两个固定风格模板，开箱即用
- **参数可配置（女孩模式）**：头顶道具、发饰、发型、表情均可按需调整，未指定则走默认
- **批量变体**：要求"多张/几张"时默认生成 3 张，同风格下做细微差异
- **固定模板兜底**：所有装饰元素由模板固定，保证出图风格稳定统一

## 🔍 什么时候用

用户上传儿童照片，并要求生成以下内容时触发：

- 贴纸头像 / 手账风头像 / 可爱大头照
- Q版大头贴 / 白底头像贴纸

> ⚠️ 必须**上传儿童人脸参考图**才能生成；纯文字描述无法替代（需保留真实面部特征）。

## 📋 使用前须知（前置条件）

1. 需要一张**清晰的正面儿童人脸照**（非正面或模糊可尝试，但效果会打折）
2. **必须先确认性别**（男孩 / 女孩）——这是路由到对应模板的前提
3. 男孩模式还需在 **模板A（Y2K）** 与 **模板B（藏式坏笑）** 中二选一

## 🎨 模式详解

### 👧 女孩模式（真实脸部 · 贴纸装饰）

| 参数 | 默认值 | 是否可改 |
|------|--------|----------|
| 头顶道具 | 带绿叶和果柄的红苹果 | ✅ |
| 发饰 | 两侧各一串彩色小花发夹（粉/黄/蓝/紫） | ✅ |
| 发型 | 双丸子头，黑色头发 | ✅ |
| 表情 | 灿烂笑容露小牙、粉嫩腮红、珠光亮片唇彩、圆大眼睛 | ✅ |
| 生成数量 | 1 张（"多张"时默认 3 张） | ✅ |

固定不可改：白底、白色描边、四角五角星、贴纸装饰风、真实照片质感脸部、1:1 构图。

### 👦 男孩模式（两个固定模板，二选一）

| 模板 | 风格 | 固定元素 |
|------|------|----------|
| **A · Y2K未来感** | 未来感、俏皮 | 未来感耳机、Y2K闪星、往右侧看的"偷偷看"眼神；若原图没戴帽子，默认用红苹果替代头顶装饰 |
| **B · 藏式坏笑** | 藏式风情、痞气 | 绿松石藏式耳环、老式墨镜（不遮额头）、一点雀斑、轻微坏笑 |

> 男孩模式仅**生成数量**可配置（默认 1 张，多张默认 3 张）；模板内的装饰元素不可修改。

## ⚙️ 生成参数参考

每次调用 `ImageGen` 图生图时使用（由 skill 自动设置）：

| 参数 | 值 | 说明 |
|------|-----|------|
| `image` | 参考图路径/URL | **必须传**，否则无法保留面部特征 |
| `size` | `1024x1024` | 1:1 方图，实测可用 |
| `quality` | `high` | 高清细节 |
| `input_fidelity` | `0.9` | 实测保真最佳：真实脸部与装饰元素兼顾 |

## ⚠️ 注意事项

- 女孩模板的固定元素、男孩两个模板的装饰元素**不可随意更改**
- 模板A帽子兜底：原图无帽时自动换红苹果，并会告知你
- 参考图中的衣服、身体、原背景会在生成时去除，只保留头部
- 单次生成建议不超过 **4 张**变体，避免调用过大

## ❓ 常见问题

**Q：没有参考图可以生成吗？**
A：不可以。必须有儿童人脸参考图，否则无法保留真实面部特征，会提示你先上传。

**Q：女孩模式想换个道具/表情？**
A：直接说，如"头顶换成蝴蝶结""表情换成鬼脸"，未说的部分走默认。

**Q：生成的图不够像？**
A：尽量使用正面清晰照；模糊或侧脸会降低相似度，但仍会尝试生成。

**Q：男孩模板能改元素吗？**
A：不能。两个模板的元素是固定的，仅数量可配置；想要不同风格可先说明再选模板。

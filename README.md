# 🎒 幼稚园 · Child Sticker Avatar

## 上传一张自身儿童人脸参考图，生成**白底大头像**。真实照片质感的脸部 + 贴纸/手账风装饰，可输出贴纸头像、Q版大头贴、可爱大头照等 1:1 方图。



## 🔍 什么时候用

用户上传自身儿童照片，并要求生成以下内容时触发：

- 贴纸头像 / 手账风头像 / 可爱大头照
- Q版大头贴 / 白底头像贴纸

> ⚠️ 必须**上传自身儿童人脸参考图**才能生成；纯文字描述无法替代（需保留真实面部特征）。

## 📋 使用前须知（前置条件）

1. 需要一张**清晰的正面自身儿童人脸照**（非正面或模糊可尝试，但效果会打折）
2. **必须先确认性别**（男孩 / 女孩）——这是路由到对应模板的前提
3. 确认性别后再选风格模板：男孩在 **模板A（Y2K）** 与 **模板B（藏式坏笑）** 中二选一；女孩在 **模板G1（贴纸装饰）** 与 **模板G2（公主风）** 中二选一

## 🚀 快速开始

直接对 任意agent 说：

> "把我上传的这张照片做成白底贴纸头像，是女孩"

```text
[上传照片] + "做成贴纸头像"
```

AI 会依次：确认性别 → 读取参考图 → 提取可选参数 → 图生图生成 → 交付图片。


## 🎨 模式详解

### 👧 女孩模式（真实脸部 · 双模板，二选一）

**G1 · 贴纸装饰**（默认）

| 参数 | 默认值 | 是否可改 |
|------|--------|----------|
| 头顶道具 | 带绿叶和果柄的红苹果 | ✅ |
| 发饰 | 两侧各一串彩色小花发夹（粉/黄/蓝/紫） | ✅ |
| 发型 | 双丸子头，黑色头发 | ✅ |
| 表情 | 灿烂笑容露小牙、粉嫩腮红、珠光亮片唇彩、圆大眼睛 | ✅ |
| 生成数量 | 1 张（"多张"时默认 3 张） | ✅ |

固定不可改：白底、白色描边、四角五角星、贴纸装饰风、真实照片质感脸部、1:1 构图。

**G2 · 公主风**

| 参数 | 默认值 | 兜底规则 |
|------|--------|----------|
| 发型 | 自然长卷发，黑色头发 | 原图为短发 → 降级为半扎发，并告知 |
| 表情 | 甜美微笑，粉嫩腮红、圆大眼睛 | — |
| 生成数量 | 1 张（"多张"时默认 3 张） | — |

固定不可改：白底、白色描边、头顶水晶钻石皇冠、珍珠蝴蝶结发饰、四角淡金小星星、珠光氛围、真实照片质感脸部、1:1 构图。

### 👦 男孩模式（两个固定模板，二选一）

| 模板 | 风格 | 固定元素 |
|------|------|----------|
| **A · Y2K未来感** | 未来感、俏皮 | 未来感耳机、Y2K闪星、往右侧看的"偷偷看"眼神；若原图没戴帽子，默认用红苹果替代头顶装饰 |
| **B · 藏式坏笑** | 藏式风情、痞气 | 绿松石藏式耳环、老式墨镜（不遮额头）、一点雀斑、轻微坏笑 |

> 男孩模式仅**生成数量**可配置（默认 1 张，多张默认 3 张）；模板内的装饰元素不可修改。

## ⚙️ 生成参数参考

每次调用 `ImageGen` 图生图时使用（由 skill 自动设置）：

| 参数 | 值 | 说明 |
|------|-----|------|
| `image` | 参考图路径/URL | **必须传**，否则无法保留面部特征 |
| `size` | `1024x1024` | 1:1 方图，实测可用 |
| `quality` | `high` | 高清细节 |
| `input_fidelity` | `0.9` | 实测保真最佳：真实脸部与装饰元素兼顾 |

## ❓ 常见问题

**Q：没有参考图可以生成吗？**
A：不可以。必须有自身儿童人脸参考图，否则无法保留真实面部特征，会提示你先上传。

**Q：女孩模式想换个道具/表情？**
A：直接说，如"头顶换成蝴蝶结""表情换成鬼脸"，未说的部分走默认。

**Q：女孩想用公主风模板？**
A：说"选公主风"即可（默认是贴纸装饰模板）。公主风固定钻石皇冠 + 珍珠蝴蝶结；若孩子是短发，发型会自动降级为半扎发并告知你。

**Q：生成的图不够像？**
A：尽量使用正面清晰照；模糊或侧脸会降低相似度，但仍会尝试生成。

**Q：男孩模板能改元素吗？**
A：不能。两个模板的元素是固定的，仅数量可配置；想要不同风格可先说明再选模板。
